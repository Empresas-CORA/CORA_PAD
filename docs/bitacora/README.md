# Bitácora

Registro **solo-adición** de lo que se hace en este proyecto (protocolo P4).

- Una entrada = un archivo nuevo, con el nombre `AAAA-MM-DD_HHMM_<autor>_<slug>.md`.
- Usa `_PLANTILLA.md`.
- Nunca se edita ni se borra una entrada. Para rectificar, crea una entrada de tipo `correccion` que apunte a la anterior.
- Un hook bloquea editar o sobrescribir entradas existentes.
- Para ver lo más reciente: `ls docs/bitacora | sort | tail`.
